# playground/

这里存放 **Stellaria Creative Tuition** 的个人原创贡献。

推荐结构：

```text
playground/<github-id>/README.md
playground/<github-id>/<your-small-asset>
```

例如：

```text
playground/example/README.md
playground/example/art.webp
```

要求见仓库根目录 [CONTRIBUTING.md](../CONTRIBUTING.md)。

请只提交你有权公开和再许可的内容；不要提交凭据、隐私信息、来源不明的大型第三方素材或可执行二进制。

如果你只是想交传统 Dress Tuition，请继续使用上游保留的 `A-Z/#/昵称/` 照片目录结构，不需要放到这里。
